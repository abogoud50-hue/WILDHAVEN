# WILDHAVEN
لعبة بقاء واستكشاف ثلاثية الأبعاد للجوال (Three.js).

- لعب فردي: انشرها على GitHub Pages أو افتح `index.html` عبر أي خادم ثابت.
- لعب جماعي محلي: `npm install && node server.js` على جهاز متصل بنفس الـ Wi-Fi أو نقطة الاتصال، ثم افتح العنوان المطبوع من كل الأجهزة. من ⚙ الإعدادات: المضيف يضغط «استضافة» ويشارك الرمز، والبقية تدخل الرمز وتضغط «انضم».
